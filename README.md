# Olá Mundo Moderno 🚀

Uma aplicação web moderna e interativa de **Olá Mundo** desenvolvida em HTML5, CSS3 avançado e JavaScript puro.

## ✨ Funcionalidades
- **Tema Branco Elegante:** Interface limpa, minimalista e moderna em modo claro com elementos em *glassmorphism*.
- **Tela de Login e Registo:** Alternador fluido entre abas, indicador de força de senha, visualização de senha, login social e notificações interativas.
- **Tipografia Premium:** Tipos de letra do Google Fonts (*Outfit* e *Plus Jakarta Sans*).
- **Multilíngue:** Suporte para alternar entre Português, Inglês, Espanhol e Francês em tempo real.
- **Interatividade:** Efeito comemorativo de partículas/confetes e contador de cliques.
- **Totalmente Responsivo:** Otimizado para qualquer dispositivo (desktop, tablet e mobile).

## 🚀 Como Executar Localmente

### Opção 1: Abrir diretamente no navegador
Abra o ficheiro `index.html` em qualquer navegador web moderno.

### Opção 2: Com servidor local (Python)
```bash
python -m http.server 8080
```
Acesse no navegador: `http://localhost:8080`

### Opção 3: Com Node.js
```bash
npx serve .
```

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 (Flexbox, Animações, Glassmorphism, Variáveis CSS)
- JavaScript Vanilla (Canvas API para partículas)
